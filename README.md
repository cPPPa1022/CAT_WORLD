# 小猫的世界 · world-sim

**一个 AI 驱动的世界模拟器：你写一行字，世界自己往下长。**

不是聊天机器人，也不是"AI 帮你写小说"。它是一个**有账本、有时间、有记忆、有遗忘**的小世界：
你扮演世界里的一个人，NPC 按自己的日程过日子、自己开口说话、自己记住你做过什么；
AI 负责"演"，引擎负责"记账"——谁在哪、几点了、钱够不够、你凭什么知道这件事。

> 零依赖：只需要 **Node.js ≥ 18**（打包版连 Node 都不需要）。
> 单页前端 + 本地小服务 + 可选 Electron 壳。没有数据库、没有云、没有账号。

---

## 一、怎么玩（三种方式）

### 1. 打包版（推荐给"只想玩"的人）
拿到 `世界模拟器` 文件夹 → 双击里面的 **世界模拟器.exe** → 直接开玩。
- 不需要装 Node、不需要联网（除了调 AI 的那一步）
- 你的存档在 `%APPDATA%\world-sim\`，不在这个文件夹里（删文件夹不会丢档）

### 2. 源码跑（推荐给"想改"的人）
```bash
cd world-sim
npm run start:web        # 起本地服务，浏览器打开 http://127.0.0.1:3088
# 或者
npm start                # Electron 窗口版（需要先 npm i 装 electron，仅开发用）
```
零运行时依赖，`npm i` 只装 electron 与打包器。

### 3. 不配 AI 也能进
不填 API 就是**演示模式**：世界照常跑，台词与剧情由本地桩函数给。
主菜单点「看一局」直接进 1996 年的青石镇。

## 二、接入 AI（这一步决定它好不好玩）

游戏内 **⚙ 设置** → 填三项（任何 **OpenAI 兼容**接口都行：官方、DeepSeek、通义、本地 Ollama/vLLM…）：

| 项 | 例子 |
|---|---|
| `baseURL` | `https://api.deepseek.com/v1`（**要带 /v1**，写的是"聊天补全"的根） |
| `apiKey` | `sk-...` |
| `model` | `deepseek-chat` |

配好之后，同一个设置页还能单独给"消息回复 / 世界演算 / 摘要"等**副线**指定另一个更便宜的模型。

**它能烧多少 token**：一回合 = 主 AI 一次（资料包 20~60K 输入）+ 在场 NPC 各自开口 + 偶尔生成器造人/造事。
自动建档（读一张大卡）是最贵的一步：分析 ≈ 15 万输入 token，建世界 ≈ 20 万、要 2~4 分钟。
所有调用都记在**流量台**里（见下），一笔一笔可查。

## 三、世界是怎么转起来的（一分钟版）

| 层 | 谁说了算 | 举例 |
|---|---|---|
| **确定性侧（代码）** | 时间推进、移动耗时、NPC 日程与位置、买卖与钱、睡眠跳跃、天气预报、逐年演算 | 说"去买包烟"→ 扣钱、进背包、落账本 |
| **叙事侧（AI）** | 台词、旁白、动作、氛围、情绪、临时小决定、**提议式**变更 | 她怎么接这句话、屋里什么味道 |
| **门控（代码）** | 你只能知道你该知道的 | 没见过的人不会显示名字；没去过的地点是灰点 |

三条铁律：
1. **AI 只提议，引擎才改世界**（变更走 Update 契约，逐条校验，写不进就当场退回重写一次）。
2. **散文不是记忆**：正文进存档给人看；世界记住的是记忆/事件/账本。
3. **世界不等你**：你不在场时，别的人也在过日子（镜头外事件、主动联系、逐年演算）。

### 钱与账（v3.20 起）
- AI **看得见**你的钱包（现金/电子/币种），也看得见**这个年代能怎么付钱**（有手机就能转账；没电子支付的年代走银行/钱庄）。
- 你说"把欠的房租转过去"→ AI 提议 → **引擎真的扣钱**（先扣电子再扣现金）并落账本；
  **钱不够就打回**，剧情必须写成"没办成"，不许假装付了。
- **欠账是一等公民**：谁欠谁多少、欠的是什么、什么时候该还，记一次，之后每回合引用它，不许改口。

## 四、目录结构（想看代码从这里进）

```
world-sim/
├─ server.js              本地服务（HTTP API + 静态文件 + 端口探测）
├─ electron-main.js       Electron 壳（窗口/标题/托盘）
├─ src/                   引擎（40 个模块，全部零依赖）
│  ├─ ai.js               提示词装配厂 + LLM 客户端 + 资料包（packetFor）
│  ├─ game.js             回合管线：意图 → 推进 → 主 AI → 校验 → 提交 → 投影
│  ├─ runtime.js          时间/日程/校验器（Update 白名单的门就这儿）
│  ├─ contract.js         ★ 契约单一真源（Update 类型 / beat 槽位 / 上下文分层）
│  ├─ store.js            存档读写（原子写、账本只追加）
│  ├─ accounts.js         钱与账（金额归一 + 找账）
│  ├─ import.js           角色卡解析 + 扫描 AI（三步建档的第 1~2 步）
│  ├─ opening.js          开局编译（第 3 步：把世界声明翻译成这个人的字段）
│  ├─ creator.js          生成框架（世界自己长出来的板块/悬浮窗，风格由 AI 定）
│  ├─ gate.js             知识门控（名字/传闻/未解锁）
│  ├─ presentation.js     场景画与工具注册表（手机/舆图/信匣…按时代推）
│  └─ …
├─ public/                单页前端（app.js / board.js / *.css）
├─ scripts/               100+ 个断言脚本（见下）
└─ data/                  开发模式的数据根（**已被 .gitignore 忽略**）
```

**改动流程**（这个仓库的规矩）：改码 → `node --check` 全过 → 跑断言 → `node scripts/deploy-dist.js` → `node scripts/dist-check.js` → 重启模拟器。
版本号写在四处（`server.js` / `public/app.js` / `electron-main.js` / `public/index.html` 的 `?v=`），
`ui-shell-check` 会盯着它们别走散。

### 跑测试
```bash
cd world-sim
npm test                          # = node scripts/run-all.js --assert-only（断言类全量，失败即非零退出）
node scripts/money-account-check.js   # 单跑某一条：钱与账
node scripts/dist-check.js            # 交付副本 == 源码（漏同步时只有它会红）
```
断言脚本不是摆设：它们是这个项目**唯一可信的回归**——每一条都对应一次真实踩过的坑。

## 五、外置调试工具（**不在本仓库里**）

这三个是本机开发用的外置装置，只读、不碰模拟器代码，放在仓库外的 `.dsh/tools/`：

| 工具 | 回答什么问题 |
|---|---|
| **wsq 查询台** | 这个世界的数据库现在长什么样（表 → 行 → 完整 JSON，走 `/api/db` 拿**内存态**） |
| **llm 流量台** | **AI 到底返回了什么**（每一次调用的请求与响应，一字不改） |
| **prompt 提示词工作台** | **AI 拿到了什么**（所有提示词逐字节，跑在桩响应里，不发真请求） |

分工一句话：**门在模拟器里，钥匙在工具手里。**
因为仓库不含它们，克隆下来只跑模拟器是完全正常的；缺的只是"看一眼内部"的窗口。
