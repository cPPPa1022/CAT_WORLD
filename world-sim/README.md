# world-sim — 初版原型

AI 驱动的世界模拟 SLG 的可运行初版。文档见《设计总稿.md》。

## 运行
```
node server.js
# 浏览器打开 http://127.0.0.1:3088
```

## 两种模式

- **演示模式**（默认，无需模型）：内置『九十年代 · 青石镇』示例世界（沈姨/阿岩，大哥大时代），模拟 AI 跑通完整回合管线：意图解析→时钟→NPC tick→漏斗→校验→提交→投影，含记忆衰减/激活、消息/已读不回、时间感知（有表/大哥大→精确，无→时段）、认知地图（知识门控）、人物档案门控（隐藏性格锁定）、睡眠跳跃+离场消息、剧本存档、ASCII 场景画、世界声明式工具（大哥大只有消息/通讯录）。
- **接入模式**：编辑 config.json 填入 `llm.baseURL`（OpenAI 兼容）+ `apiKey` + `model`，重启后主 AI/副 AI/扫描 AI 全部走真实模型（DeepSeek/Clash 代理上的任意兼容端点均可）。

## 卡牌导入

UI 右下角【导入】: 粘贴角色卡 JSON 文本 / 上传 PNG 卡片(v2 chara 块) / 上传 .json。
演示世界骨架不变，导入将替换：NPC（赵子俊→你的卡）、玩家档案、开场白、时代载体假设（现代）。完整世界包生成（地图/关系网/世界假设书的自动扫描）在 Roadmap。

## 目录

- src/store.js — 世界库（实体/记忆/流水账/知识视图 + JSON 持久化）
- src/world.js — 演示世界种子（便利店雨夜）
- src/runtime.js — 时钟/日程 tick/移动/校验器/漏斗/记忆衰减激活
- src/ai.js — Prompt 装配 + LLM 客户端 + 演示模式模拟 AI
- src/game.js — 回合管线（意图解析→推进→主AI→校验→提交→投影）
- src/import.js — 卡牌解析（JSON/PNG v2/文本）+ 扫描 AI
- server.js — 本地 Web 服务（静态 UI + JSON API）
- public/ — 终端风单页 UI

## 关键设计（对应设计总稿）

- AI 提议、运行时提交：所有 Update 过校验器（ID 存在/白名单/锁定字段/因果/画面↔Update 映射），失败打回 → 保守发布，世界不回滚。
- 事实账本：ledger 追加式，永不修改删除；实体当前状态 = 账本重放。
- 记忆：冲击力 → 权重=冲击力×e^(-λΔt)+波动；写入时标签重叠旧记忆获得加成（关联激活）；同标签近期重复合并（去重）；遗忘不删除。
- 知识门控：knownPlaces/knownPeople/readMsgs → 地图、人物、新闻、概况模块只显示你知道的。
- 时间感知：有计时设备（手机/手表）→ 精确时刻；无 → 白天/傍晚/夜晚（体感）。
- 不是每一句都要回复：NPC 可能已读不回（演示：赵子俊烦躁且无道歉语 → 已读不回）。
