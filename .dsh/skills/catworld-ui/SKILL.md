# 世界剧 UI 设计系统

## 0. 依据
抄自 **TUI 设计系统**（`pedronauck/skills` → `tui-design`，MIT）+ 本项目的《世界剧设计纲领》§3。
核心哲学：**用空间一致性、信息密度、以及对人的注意力的尊重换取力量。**

## 1. 三层法则（最重要，先看这条）

> **80% 的内容用正文色。标题靠加粗+提亮。元信息变暗。强调色只给可交互元素。**

违反它 = 满屏都在喊，等于没有层次。**实测反例**：改前 `--mint` 同时用于场景标签边框、按钮、链接、人名、焦点——颜色是装饰不是语义。

## 2. 语义色板（`public/style.css` 的 `:root`）

**按功能定义，不按外观。改配色只改这里的值**（全套 UI 自动跟随）：

| 变量 | 角色 | 值 | 用在 |
|---|---|---|---|
| `--bg1/--bg2` | bg.base | #15161d / #191a23 | 页面底 / 应用底 |
| `--panel/--panel2` | bg.surface | #1f2029 / #262833 | 面板 / 浮层（**每级约 +6% 亮度制造纵深，少用边框**） |
| `--line/--line2` | 分隔 | #282a36 / #3a3d4d | 仅在纵深不够时用 |
| `--fg` | fg.default | #c6cad8 | **正文（80%）** |
| `--dim/--dim2` | fg.muted | #8a90a6 / #5c6178 | 元信息 / 弱信息 |
| `--mint` | **accent.primary** | **#e8b45c 琥珀** | 按钮/焦点/链接/场景标签——**只给可交互** |
| `--cyan` | accent.secondary / info | #7dcfff | 说话者名、次要交互 |
| `--amber` | warning | #d9a15e | 天气、玩家的痕迹 |
| `--red` | error | #f7768e | 错误 |

**为什么主强调是琥珀而不是薄荷绿**：90 年代是 **P3 磷光屏（琥珀）**，绿色是更早的 P1。琥珀既贴年代，又合"群像生活剧"的暖调。

## 3. 反模式清单（按真实抱怨频率排序，改完逐条对）

| # | 反模式 | 本项目的历史现场 |
|---|---|---|
| 1 | **颜色是装饰不是语义** | `--mint` 一色多用 |
| 2 | **过度装饰**："边框和颜色服务内容，不服务自尊。**内容本身就是界面**" | 场景画的卡片框、满屏天气斜线 |
| 3 | **元信息对比度不足** | `--dim2` 对底不足 3:1 |
| 4 | **界面被装饰抢戏** | 天气效果铺满舞台，盖住文字 |
| 5 | **未做渐进披露** | 顶栏 16 个图标平铺，没有"更多" |
| 6 | **颜色是唯一信息载体** | 需与符号/文字/位置配对（无障碍） |

## 4. 越权红线（来自设计纲领 §3，改 UI 必须过）

1. **屏幕只放三样**：感知 / 认知 / 行动。世界的真相、进度、数值、系统术语**一律不出现**。
2. **diegetic 分层**：判断标准一句话——**"这个东西在 1996 年的青石镇存在吗？"**
   - 存在（大哥大界面/舆图/信匣）→ 必须像那个年代
   - 不存在（窗口边框/设置/皮肤）→ 随便你，猫放这里永远不 OOC
3. **不给建议，给观察**：chips 是"你注意到的东西"（渲染 `V.interacts`，点开是子菜单），**不是"你该做什么"**。
4. **开发者信息不上桌**：`回合 #N` / LLM 用时 / token / 缓存 **只在 `?dev` 时显示**。

## 5. 改完怎么验（现在能自测了）

```powershell
# 1) 起服务（临时数据目录，别碰用户存档）
$env:PORT='3909'; $env:WORLD_SIM_DATA='<workspace>\.tmp-ui\data'; $env:WORLD_SIM_ASSETS='<repo>\world-sim'; node server.js
# 2) 真实浏览器验收 + 截图
cd '<workspace>\.dsh\tools\verify'
node "node_modules\dsh-verify\bin\verify.mjs" --spec "specs\xxx.json" --out "out\xxx" --json
# 3) 用 read_image 看 shot-N.png —— 一定要亲眼看，断言测不出"丑"
```
**spec 坑**：`{steps:[...]}` 对象，不是裸数组；`expect_console_errors` 要断言零报错得写 `present:false`；`click` 支持 `text=演示世界`。
**选择器坑**：同名按钮多处出现时 `text=设置` 会命中隐藏的那个（Timeout）。用 `#start-menu >> text=设置`、`button:has-text("进入")` 这类限定选择器。

### ⚠️ 两条必守的测试纪律（血泪）

1. **杀掉泄漏的服务进程**：`job_kill` 只杀 pwsh 外壳，**子进程 `node server.js` 不会退出**。
   累积 9 个僵尸实例后，其中最早那个占着测试端口，**读到的是旧世界/旧配置**，能排查半天。
   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
     Where-Object { $_.CommandLine -match 'server\.js' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
   ```
2. **world 与 config 被服务端缓存在内存**：运行中改磁盘文件**不生效**，而且会被内存副本**覆盖回去**。
   要注入测试数据（假图/假任务/enabled 开关）必须**先停机、改文件、再启动**。
3. **临时数据目录有两层**：`WORLD_SIM_DATA=X` → config 在 `X/config.json`，世界在 `X/data/worlds/*.json`，画廊在 `X/data/gallery/<worldId>/`。

### 造一张假图来验生图链路（不用真 ComfyUI）
手写一个 PNG（zlib deflate + CRC32，约 30 行）→ 写 `X/data/gallery/<wid>/` + `gallery.json` → 往世界 JSON 的 `current.imgTasks` 注入一条 `status:'done'`。
**并在 note/state 里塞探针字符串**（如 `'LEAK-测试'`），用来断言内部信息没被泄露到界面。
**数据目录会持久**：同一个 temp 目录跑第二次时世界已加载，**没有"演示世界"按钮了**，spec 要相应去掉 click。
