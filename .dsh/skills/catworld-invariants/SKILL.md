# 不变量清单（违反即返工）

## 1. 知识门控：玩家只能知道自己知道的
| 数据 | 显示条件 | 代码位 |
|---|---|---|
| NPC 名字 | 印象 `stage≥2`（知道名字） | `src/game.js viewName()` |
| 通讯录 | `knowledge.phoneContacts`（有号码；无号码=陌生号码） | `buildView.contacts` |
| 地图地点 | `knowledge.knownPlaces`（没去过=灰点/传闻） | `buildView.map` |
| 新闻 | `knowledge.heardNews` | `buildView.news` |
| 人物 traits/notes | 玩家印象卡（不是 NPC 档案） | `personView` |
| 我的概况 | 不门控（自己的认知） | `selfView` |

**新增任何显示字段前先问：这是玩家能知道的吗？** 名字一律走 `viewName`，不要直接读 `entity.name`。

## 2. 三投影（写台词只用第三投影）
1. 客观事件流（`ledger`/世界真相）
2. 人物记忆视图（他记得什么：`memories` owner）
3. 玩家认知视图（你知道什么：`knowledge`/`impressions`）
信息差本身就是戏剧性引擎；口信/传闻失真（§9 信息旅程）是合法机制，不是 bug。

## 3. 职责划分（谁说了算）
- **确定性侧（代码）**：时间推进、移动与耗时、NPC 位置（日程 tick）、买卖与钱、睡眠跳跃、天气预报、日历事件触发、记忆衰减/去重/漏斗排序。
- **叙事侧（AI）**：台词、旁白、动作、氛围、情绪、临时小决定、提议式 Update。
- AI 只能**引用**确定性侧的结论；NPC 位置变化必须等于 tick 结果（例外要走"事件开始+地点变化+移动检查"）。
- **散文不是记忆**：正文进 `archives`（给人看），世界记住的是 Update/记忆/事件流。

## 4. 校验器 = 限制区执行者（`src/runtime.js validateUpdates`）
必须拒绝：未知 ID / 白名单外的 Update 类型 / 触碰 `locked.core` / 时间不一致 / 非法移动 / 关系数值化 / 新人物无 `cause+relation` / 记忆无 `impact(0-100)` / 关系变化无 `cause` / 画面与 Update 引用不闭合。打回 ≤2 次 → 保守发布，**世界时钟不回滚**。

## 5. 事件：烈度与"禁止瞎生成"（§10）
- 四烈度 L1 日常 / L2 剧情 / L3 地区 / L4 世界；L5=禁止。烈度上限来自世界包（扫描 AI 判定）。
- 三道门：**烈度上限** → **概率门**（L3+ 每 N 世界日 roll） → **前兆链**（无前兆不得凭空出现）。
- 每条事件/新闻带影响三字段：{时长: 瞬间/短期/长期, 严重性: 低/中/高/灾难, 范围: 个人圈/本地区/全国/世界}。
- 重大事件是**演化出来的**，不是掷出来的。

## 6. 无任务系统（§14）
承诺/约定 = 事件流里的一个事件类型；日历由它派生；**系统永不判定成功/失败**，只记事实，评价交给 NPC 的性格与记忆。

## 6.5 呈现门控与「零 token 自驱」原则（2026-09-10 实测新增）
- **玩家界面只呈现"玩家认知视图"**。客观事件流（`ledger`）是**导演台本**，含玩家不在场的事，绝不能进玩家 UI——**实测反例**：`game.js:862 lastLedger` → 右栏「世界账本」，把 `记忆新增/关系变化/事件开始/信息到达` 这类**数据库字段名**印在玩家脸上（剧透 + 术语出戏）。客观账本只许进诊断/观察模式与 AI 侧（`subai.js` 用它喂新闻是对的）。
- **任何自驱力/世界动态，只能经由"玩家的窗口"呈现**：消息、场景里看得见的行为、听说/传闻、回来才发现。**不得**通过系统面板播报。
- **零 token 自驱（用户 2026-09-10 定的约束）**：把"想要什么（数据）/ 什么时候动手（算术）/ 怎么开口（叙事）"三层拆开——
  - 欲望与冷却 = **世界里的一次性数据**（世界包生成时写好，游玩期 0 token）
  - 每 tick 的 pressure 计算与行动决策 = **纯算术，0 token**
  - 只有"演成文字"花 token，且**搭车**已有通道：候选写进 `pendingCandidates`（主 AI 本回合顺手演）、主动联系走既有消息 AI（`deliverPendingReplies`）
  - 玩家不可见期间**照常累积、不演出**，回来那一回合合并演完（沿用"跳跃只批量摘要"的既有护栏）
- 护栏：全服每世界日 ≤1 次"主动接触玩家"（pressure 最高者胜）、同 NPC 冷却 12-24 世界小时、作息时间窗、被无视则 urgency 衰减（NPC 会"算了"）。

## 7. AI 自由度三档（§12，提示词必须写明）
- 自由区（明确授权）：语气口癖、小动作、情绪、说什么怎么说、环境氛围、NPC 临时小决定。
- 限制区（明确禁止）：硬事实、时间/位置/天气、新人物引出因果、记忆关系因果、烈度上限、只用 ID 引用、资料包 empty=无。
- 默认区（未注明=自由）：其余一切由 AI 自行判断，不必请示、不必保守。

## 8. 其它硬约定
- 一切时间 = ISO 字符串（`src/runtime.js fmtISO`），禁止裸 Date 比较。
- 引用只用 ID；名称对照表随资料包给 AI，代码只查引用完整性，不读叙事。
- `ledger` 只追加永不删（实体当前状态 = 账本重放）。
- 货币/物品：AI 只叙事，库存与钱由 `tryPay/tryEarn` 确定性改（AI 重复写交易 Update 会被过滤）。
- 载体（手机/信匣/传音符/收音机/舆图）由 `meta.carries`+`src/presentation.js deriveTools` 推导：**没有的不显示**（无表 = 无精确时间）。

## 9. 改完之后的自检三问
1. 这个信息玩家凭什么知道？（门控）
2. 这一步是代码该算的，还是 AI 该写的？（职责）
3. AI 越线时哪一行代码会拦住它？（校验器）
